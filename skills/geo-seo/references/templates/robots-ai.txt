# robots.txt modèle : moteurs de recherche et assistants IA accueillis, application (SPA) non indexée,
# sitemaps déclarés et lisibles par tous les robots.
#
# Paramètres : [DOMAINE]; [APP] = chemin de l'application client-only (ex. /app/); [CONVERT] = chemins
# de l'application qui doivent rester indexables (ex. pages pré-rendues de conversion), à supprimer s'il
# n'y en a pas; [SITEMAP_APP] = sitemap qui vit sous le chemin interdit.
#
# POURQUOI CE FICHIER EST FAIT AINSI (leçons de la campagne) :
#
# 1. L'EXCEPTION DU SITEMAP. Un sitemap qui vit sous un chemin interdit est lui-même interdit : avec
#    "Disallow: [APP]" seul, Google ne pouvait pas lire [SITEMAP_APP] (erreur Search Console pendant
#    plusieurs semaines). Une règle "Allow" plus LONGUE l'emporte : "Allow: [SITEMAP_APP]" corrige. Elle
#    doit figurer dans CHAQUE bloc User-agent, car un robot nommé ignore le bloc générique "*".
#
# 2. L'ORDRE. Les "Allow" sont écrits AVANT les "Disallow" pour la lisibilité (la règle la plus longue
#    gagne, pas l'ordre).
#
# 3. DISALLOW ET NOINDEX. Un "Disallow" empêche le robot de LIRE la page, donc de lire un en-tête
#    "X-Robots-Tag: noindex" : il ne désindexe rien et peut laisser l'URL nue dans l'index. Pour retirer une
#    page de l'index, servir "noindex" ET laisser le robot la récupérer (pas de Disallow sur ce chemin).
#
# 4. LES ROBOTS IA. Trois familles par éditeur : robot d'entraînement (GPTBot, ClaudeBot, CCBot,
#    Google-Extended, Applebot-Extended), robot de recherche (OAI-SearchBot, Claude-SearchBot,
#    PerplexityBot, Bingbot) et robot "utilisateur" déclenché par une question (ChatGPT-User, Claude-User,
#    Perplexity-User, DuckAssistBot, MistralAI-User). Pour être cité, il faut au moins autoriser les robots
#    de recherche et "utilisateur". Autoriser l'entraînement est un choix de l'éditeur (mémoire des modèles,
#    effet lent); le choix par défaut de la campagne : tout autoriser.
#
# 5. BYTESPIDER exclu volontairement dans la campagne (pas de valeur, gros volume) : à décider.
#
# 6. Un CDN ne doit pas réécrire ce fichier : comparer à l'octet près le fichier en ligne et le fichier du
#    dépôt après chaque déploiement.
#
# 7. Chaque règle non évidente est commentée AVEC SA DATE, pour que le prochain agent sache pourquoi.

User-agent: *
Allow: /
Allow: [CONVERT]
Allow: [SITEMAP_APP]
Disallow: [APP]
Disallow: /api/
Disallow: /auth/
Disallow: /signin
