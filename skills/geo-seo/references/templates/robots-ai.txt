# Template robots.txt: search engines and AI assistants welcome, application (SPA) not indexed,
# sitemaps declared and readable by all robots.
#
# Parameters: [DOMAIN]; [APP] = path of the client-only application (e.g. /app/); [CONVERT] = application paths
# that must stay indexable (e.g. pre-rendered conversion pages), to delete if there are none; [SITEMAP_APP] =
# sitemap that lives under the forbidden path.
#
# WHY THIS FILE IS BUILT THIS WAY (lessons from the campaign):
#
# 1. THE SITEMAP EXCEPTION. A sitemap that lives under a forbidden path is itself forbidden: with
#    "Disallow: [APP]" alone, Google could not read [SITEMAP_APP] (Search Console error for several weeks).
#    A LONGER "Allow" rule wins: "Allow: [SITEMAP_APP]" fixes it. It must appear in EACH User-agent block,
#    because a named robot ignores the generic "*" block.
#
# 2. ORDER. The "Allow" lines are written BEFORE the "Disallow" lines for readability (the longest rule wins,
#    not the order).
#
# 3. DISALLOW AND NOINDEX. A "Disallow" stops the robot from READING the page, and so from reading an
#    "X-Robots-Tag: noindex" header: it deindexes nothing and may leave the bare URL in the index. To remove a
#    page from the index, serve "noindex" AND let the robot fetch it (no Disallow on that path).
#
# 4. AI ROBOTS. Three families per publisher: training robot (GPTBot, ClaudeBot, CCBot,
#    Google-Extended, Applebot-Extended), search robot (OAI-SearchBot, Claude-SearchBot,
#    PerplexityBot, Bingbot) and "user" robot triggered by a question (ChatGPT-User, Claude-User,
#    Perplexity-User, DuckAssistBot, MistralAI-User). To be cited, you must at least allow the search
#    and "user" robots. Allowing training is the publisher's choice (model memory, slow effect);
#    the campaign's default choice: allow everything.
#
# 5. BYTESPIDER deliberately excluded in the campaign (no value, high volume): to be decided.
#
# 6. A CDN must not rewrite this file: compare the live file and the repository file byte for byte after each
#    deployment.
#
# 7. Each non-obvious rule is commented WITH ITS DATE, so that the next agent knows why.
